# Test Strategy

## Objective
Validate ReqRes API functionality using Postman.

## Scope
- User APIs
- Authentication APIs
- CRUD operations

## Testing Types
- Functional testing
- Negative testing
- Response validation

## Tools

* Postman for API testing
* Newman for automation

## Entry Criteria

* API endpoints available
* Postman environment configured

## Exit Criteria

* All critical test cases pass
* No major defects
