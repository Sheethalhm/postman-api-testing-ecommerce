# Test Strategy

## Objective

To validate the functionality, reliability, and performance of the E-commerce API.

## Scope

* Authentication
* User operations
* Product retrieval
* Cart management

## Testing Types

* Functional Testing
* Negative Testing
* Regression Testing
* Basic Performance Testing

## Tools

* Postman for API testing
* Newman for automation

## Entry Criteria

* API endpoints available
* Postman environment configured

## Exit Criteria

* All critical test cases pass
* No major defects
